# 牧草地 面積計測(RichiField2)

地図上で範囲を囲むと、1m DEMから**投影面積と表面積**を計算する計測専用のWebGISです(GitHub Pagesで動作)。
計測結果は、使っているPCの**作業フォルダ**に GeoJSON と CSV で自動保存されます(スプレッドシートやサーバーには送りません)。

## フォルダ構成

```
index.html        地図本体(冒頭の CONFIG だけ編集すればOK)
data/dem.tif      面積計算用の1m DEM(メッシュ664351の筆周辺+300m、1cm丸め、COG形式)
tools/serve.py    ローカル確認用サーバー
```

## 使い方

1. 右パネルの「**作業フォルダを選ぶ**」で、保存先のフォルダを選ぶ(初回のみ。ブラウザの確認で「編集を許可」)
2. 左上の**五角形**(または四角)ボタンで範囲を囲む(黄色の点線の中が計算できる範囲)
3. 面積がポップアップに出て、名前を聞かれます(空欄でも可、あとで変更できます)。初回だけ計測者の名前も聞かれます
4. 計測を追加・修正(鉛筆)・削除(ゴミ箱)するたびに、作業フォルダの次の2つが自動で上書きされます
   - `計測範囲.geojson` … 形状と面積。次回の読み込みやQGISで使う本体
   - `計測範囲.csv` … 同じ内容の表(Excelで開けます。`WKT` 列に形状が入っているので、QGISの「区切りテキスト」でも読めます)
5. 右パネルの「計測一覧」で、名前・日時・面積・メモ・計測者と合計面積を確認。名前をクリックするとその場所へ移動

### 次に開いたとき

- 「**前回のフォルダを開く**」を押して許可すると、`計測範囲.geojson` を読み込んで続きから作業できます
  - Chromeで「サイトを訪問するたびに許可」を選ぶと、次回からはボタンを押さずに読み込まれます
- 作業フォルダを分ければ、圃場ごと・調査日ごとに別のファイルとして管理できます(「別のフォルダに切替」)

### 複数人で作業するとき

- 各自が自分のPCの作業フォルダに保存し、終わったら `計測範囲.geojson` を取りまとめ役に渡す運用をおすすめします
- 取りまとめ役は「**GeoJSONを読み込む**」で、受け取ったファイルを追加できます
  - 同じ計測(計測ID)は二重にならず、**更新日時の新しい方**が残ります
  - QGISで作ったポリゴンのGeoJSONも読み込めます(面積はDEMで計算されます)
- 「別名で書き出す」で、日付付きのGeoJSON・CSVをダウンロードフォルダに保存することもできます(配布用の控え)

共有フォルダ(OneDriveなど)を複数人が同時に作業フォルダにすると、後から保存した人の内容で上書きされます。同時に使う場合は、各自別のフォルダにしてください。

### Chrome・Edge以外のブラウザ

Firefox・Safari(iPhone)では作業フォルダへの自動保存ができません。計測はブラウザ内に残りますが、作業の区切りで「GeoJSONを保存」「CSVを保存」(ダウンロード)を押してください。続きの作業は「GeoJSONを読み込む」で再開できます。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリ `RichiField2` を作成(Public)
2. 「uploading an existing file」から `index.html`・`README.md`・`data`・`tools` をアップロード →「Commit changes」
3. 「Settings」→「Pages」→ Branch: `main` / `/(root)` →「Save」
4. `https://nabe6318.github.io/RichiField2/` で開きます

## ローカルで確認する場合

```
python tools/serve.py
```
で `http://localhost:8000` を開きます。

## 面積の計算方法

投影面積 = 囲った範囲の水平面積(JGD2011 平面直角座標 XII系)、表面積 = 投影面積 × 平均(1/cosθ)。
θ は1mセルごとの傾斜(Horn法)で、セル中心が範囲内にあるセルで平均します。
DEMは筆ポリゴンの周辺+300mだけを切り出してあるので、黄色の点線の外は計算できません。
