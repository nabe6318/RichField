# DEM 面積計測(RichiField2)

地図上で範囲を囲むと、1m DEMから**投影面積と表面積**を計算するWebGISです(GitHub Pagesで動作)。
どの地域のDEMでも使えます。区画などのポリゴン(GPKG・GeoJSON)を重ねて表示し、区画ごとの面積も計算できます。
データはすべて使っているPCの中で処理され、サーバーやスプレッドシートには送りません。

## フォルダ構成(リポジトリ)

```
index.html        地図本体(冒頭の CONFIG だけ編集すればOK)
data/dem.tif      サンプルDEM(北海道興部町 メッシュ664351の一部)
tools/serve.py    ローカル確認用サーバー
```

## 基本の使い方:地域ごとの「作業フォルダ」

1. PCに地域ごとのフォルダを作り、次のファイルを入れる
   - **DEM**:GeoTIFF(`.tif`)。何枚でも可(隣り合うメッシュを分けたままでOK)
   - **レイヤ**:区画などのポリゴン(`.gpkg` または `.geojson`)。何個でも可
2. 地図の右パネルの「**作業フォルダを選ぶ**」でそのフォルダを選ぶ(ブラウザの確認で「編集を許可」)
   - DEMとレイヤが自動で読み込まれ、その場所へ移動します
3. 範囲を囲む・区画の面積を計算する(下記)
4. 計測した範囲は、同じフォルダの `計測範囲.geojson`(本体)と `計測範囲.csv`(Excel用)に自動で保存されます
5. 次に開いたときは「**前回のフォルダを開く**」で続きから。別の地域は「別のフォルダに切替」

```
例)C:\面積計測\伊那_ほ場A\
      dem_5338xxxx.tif        ← DEM
      ほ場区画.gpkg            ← レイヤ
      計測範囲.geojson         ← アプリが作る(計測)
      計測範囲.csv             ← アプリが作る(計測の表)
```

作業フォルダは Chrome・Edge で使えます。Firefox・Safari では「DEMを追加」「レイヤを追加」でファイルを選び、計測は「保存」でダウンロードしてください。

## 範囲を囲んで測る(計測)

- 左上の**五角形**(または四角)ボタン → 地図をクリックして範囲を囲む → 面積がポップアップに出て、名前を聞かれます
- 修正は鉛筆、削除はゴミ箱ボタン。右パネルの「計測一覧」で名前・面積・合計を確認
- 計測を他の人に渡すときは `計測範囲.geojson` を渡し、受け取った人は「他の計測ファイルを読み込む」で追加(同じ計測は更新日時の新しい方が残ります)

## レイヤ(GPKG・GeoJSON)

- 区画をクリック → 属性の一覧。「**面積を計算**」でその区画の投影面積・表面積、「**計測に追加**」で計測一覧にコピー(名前・メモを付けて保存できます)
- 右パネルのレイヤ欄
  - **ラベル**:表示する列を選ぶ(ズーム15以上で表示。`name`・`名前`・`圃場名` などの列は自動で選ばれます)
  - **全区画の面積を計算** → 計算後に「書き出し CSV / GeoJSON」で、元の属性+面積の列を保存
- GPKGに複数のレイヤ(テーブル)があれば、すべて読み込みます
- 座標系はファイルから自動で判定して表示します(平面直角座標・UTM・緯度経度など)

## DEMについて

- 座標系はGeoTIFFから自動で判定します。対応:JGD2011/JGD2000 の平面直角座標 I〜XIX系、UTM 51〜55帯、緯度経度(JGD2011・WGS84)。判定できないときは、EPSGコードか系番号を聞かれます
- 計算には自分で読み込んだDEMを優先し、無い場所だけサンプルDEMを使います
- 黄色の点線がDEMの範囲です。範囲の外は表面積を計算できません(投影面積だけ出ます)
- 1回に計算できる大きさは約800ha(1mDEM)まで。`CONFIG.maxCells` で変更できます

### 国土地理院の1mDEMを使うとき

基盤地図情報(数値標高モデル 1mメッシュ)のXMLは、QGISのプラグイン(QuickDEM4JP など)や「基盤地図情報ビューア」でGeoTIFFに変換できます。
緯度経度のままでも使えますが、QGISで平面直角座標(長野なら VIII系 EPSG:6676)に変換しておくと、QGISで計算した面積と一致します。
大きいDEMは「ラスタ → 変換 → 変換(形式変換)」で 圧縮 DEFLATE・タイル化(`TILED=YES`)しておくと、読み込みが速くなります。

## 面積の計算方法

- 投影面積:範囲の水平面積。DEMが平面直角座標などの場合はその座標系で計算(QGISの面積と一致)。緯度経度のDEMだけの場合は、範囲の中心を原点にした横メルカトルで計算
- 表面積:投影面積 × 平均(1/cosθ)。θ は1mセルごとの傾斜(Horn法・3×3)で、セル中心が範囲内にあるセルで平均
- 検証:北海道興部町の33区画で、Python(rasterio)で計算した値と0.01%未満で一致。傾き30°の人工斜面で理論値の面積比 1.1547 を再現(緯度経度・平面直角どちらのDEMでも)

## 公開・ローカル確認

- GitHub Pages:リポジトリに `index.html`・`README.md`・`data`・`tools` を置き、「Settings」→「Pages」で `main` / `/(root)`
- サンプルDEMが不要なら、`index.html` の `CONFIG.dems` を `[]` にし、`data/dem.tif` を削除
- ローカルで確認:`python tools/serve.py` → `http://localhost:8000`
