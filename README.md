# 牧草地 面積計測(RichiField2)

地図上で範囲を囲むと、1m DEMから**投影面積と表面積**を計算する計測専用のWebGISです(GitHub Pagesで動作)。
計測結果はGoogleスプレッドシートの「計測」シートに保存され、ほかの端末からも見られます。
あわせて、手元のPCにGeoJSONファイルとして保存し、次に開いたときに読み込めます。

## フォルダ構成

```
index.html        地図本体(冒頭の CONFIG だけ編集すればOK)
data/dem.tif      面積計算用の1m DEM(メッシュ664351の筆周辺+300m、1cm丸め、COG形式)
gas/Code.gs       スプレッドシートの読み書きAPI(RichField と共用)
tools/serve.py    ローカル確認用サーバー
```

## 使い方

1. 左上の**五角形**(または四角)ボタン → 地図をクリックして範囲を囲む(黄色の点線の中が計算できる範囲)
2. 面積がポップアップに出て、名前を聞かれます(空欄でも可、あとで変更できます)
3. そのまま「計測」シートに保存されます
   - 初回だけ、計測者の名前と合言葉を聞かれます(端末に記憶)
4. 右パネルの「計測一覧」で、名前・日時・面積・メモ・計測者と合計面積を確認。名前をクリックするとその場所へ移動
5. 範囲の修正は鉛筆ボタン(面積を計算し直してシートも更新)、削除はゴミ箱ボタンか一覧の「削除」(シートからも削除)

一覧の色:青=シート保存済、橙=未送信(通信失敗など。「シートに送る」で再送)、灰=ローカルファイルから読み込んだだけ。

## ローカルのGeoJSONファイル(Chrome・Edge)

- 「**ローカルに保存**」で保存先のファイル(例 `計測範囲.geojson`)を一度選ぶと、以後は計測を追加・修正するたびに自動で上書きされます
- 次にこの画面を開くと「**前回のファイルを読み込む**」ボタンが出ます。押して許可すると、そのファイルの計測が地図に表示され、自動上書きも再開します
  - Chromeで「サイトを訪問するたびに許可」を選ぶと、次回からはボタンを押さずに読み込まれます
- 「ファイルを開く」で、別のGeoJSON(QGISで作ったポリゴンなど)も読み込めます。面積はDEMで計算し直し、「シートに送る」でシートにも登録できます
- 同じ計測IDのものは二重に表示されません

Firefox・Safari(iPhone)では自動上書きができないため、「GeoJSONをダウンロード」と「ファイルを開く」で保存・読み込みします。

## スプレッドシートの設定

RichField と同じスプレッドシート・同じApps Scriptを使います。

1. スプレッドシートの「拡張機能」→「Apps Script」で、コードを `gas/Code.gs` に置き換えて保存
2. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」(URLは変わりません)
3. 最初の計測を保存すると、「計測」シートが自動で作られます

「計測」シートの列:計測ID・名前・メモ・投影面積_m2・表面積_m2・面積比・平均傾斜_度・DEM被覆率・中心緯度・中心経度・作成日時・計測者・更新日時・更新者・geometry(形状。手で書き換えないでください)

## GitHub Pagesで公開

1. GitHubで新しいリポジトリ `RichiField2` を作成(Public)
2. 「uploading an existing file」から `index.html`・`README.md`・`data`・`gas`・`tools` をアップロード →「Commit changes」
3. 「Settings」→「Pages」→ Branch: `main` / `/(root)` →「Save」
4. `https://nabe6318.github.io/RichiField2/` で開きます

## ローカルで確認する場合

```
python tools/serve.py
```
で `http://localhost:8000` を開きます。

## 面積の計算方法

投影面積 = 囲った範囲の水平面積(JGD2011 平面直角座標 XII系)、表面積 = 投影面積 × 平均(1/cosθ)。
θ は1mセルごとの傾斜(Horn法)で、セル中心が範囲内にあるセルで平均します。RichField と同じ計算です。
DEMは筆ポリゴンの周辺+300mだけを切り出してあるので、黄色の点線の外は計算できません。
